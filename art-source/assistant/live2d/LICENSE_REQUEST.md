# Draft — Live2D AI/chatbot publication classification request

Do not send this draft without the project owner's approval.

Subject: Publication classification for a single-character non-commercial AI study assistant web app

Hello Live2D licensing team,

I am developing KurenaiOS, a non-commercial browser-based personal study and
collection application. It includes an AI/chat assistant represented by one
fixed original Live2D character named Kurenai.

The intended implementation has these boundaries:

- It is a web application hosted on Cloudflare Pages.
- It uses one fixed model created and owned for this project.
- End users cannot upload, import, generate, sell, exchange, or switch Live2D
  models.
- There is no avatar marketplace, VTuber tracking, model editor, SDK wrapper,
  plugin system, or user-generated character catalogue.
- The character reacts to six application lifecycle states and four fixed hit
  areas. The AI changes dialogue and application actions, but it does not
  generate or modify model files.
- The application is currently free and does not have subscriptions,
  advertising, paid items, or other revenue.
- The publisher is an individual / General User.

Could you confirm whether this use is treated as a non-expandable AI/chatbot web
application for which an individual is exempt from a Publication License
Agreement, or whether it is classified as an Expandable Application requiring
review and a special agreement? If a non-profit plan or attribution is required,
please identify the applicable plan and release steps.

Development will remain local and the Cubism runtime will not be published until
the classification is confirmed.

Project URL: https://kurenai-os.pages.dev

Thank you.
