# AQA 7516 (AS) Paper 2 — examiner's report notes

Paraphrased from AQA's *Report on the Examination* (saved in your folder by
`tools/fetch_reports.py`), in our own words, citing series and question.
AS Paper 2 is the A-level Paper 2 content at AS depth, so these traps
apply there too.

---

## June 2022

### Q01.2 (2) · 4.5.1.1 irrational numbers
- Trap: "an infinite decimal". 0.333… is 1/3. Irrational = **can't be
  written as a fraction** of two integers.

### Q01.3 (2) · 4.5.1.1 shade one lozenge per column
- Under a quarter got both — mostly by shading more than one per column
  against the instructions.

### Q03.1 (2) · 4.5.4.1 range of 16-bit unsigned
- Trap: 65 536 and 1. It is **0 to 65 535**.

### Q03.2 (2) · 4.5.4.1 binary multiplication
- Write the trailing 0s on each partial product (10101__ is not 1010100);
  it went unpenalised this time but may not again.

### Q04.1 (1) · 4.5.5.1 character code
- "A code for a character" just restates the question: it is the
  **unique binary number** that represents a character in a character set.

### Q04.2 (2) · 4.5.5.1 why Unicode came in
- Answer **why it was introduced** (ASCII's 7/8 bits couldn't hold the
  world's scripts and symbols), not Unicode's advantages.

### Q04.3 (2) · 4.5.5.3 how parity works
- "Checks the number of 1s" was vague: the sender **counts the 1s** and
  sets the bit to make the total even/odd; the receiver counts again.

### Q04.5 (3) · 4.5.6.10 Vernam by hand
- Half full marks. Many did only the ASCII step; trap: **adding** the key
  instead of **XOR**. The ASCII step alone earns a mark — attempt it.

### Q05.2 (3) · 4.5.6.1 how an ADC works
- Under a quarter full marks. The wave becomes an **electrical signal**;
  the ADC samples that signal's amplitude at intervals and quantises
  each sample to an integer, then codes it in binary.

### Q06.2 (2) · 4.6.1.3 two other kinds of system software
- Trap: naming translators when the question said "other"; or OS
  functions. Utilities, libraries, operating system…

### Q06.3–Q06.4 (2+1) · 4.6.3.1 intermediate language
- Badly answered (1 in 8 left it blank). IL needs **further translation**
  on the target, by a virtual machine or a JIT compiler; it is used because
  it is processor-independent (portable).

### Q07.4–Q07.5 (3+4) · 4.6.5.1 Boolean
- Spot when a truth table equals A·B instead of grinding laws.
- Trap when expanding brackets: one half was AND, the other OR — the
  operators don't all become +. Practise many shapes.

### Q08.2 (2) · 4.7.1.1 RAM's role in running programs
- "Stores data" wasn't enough: it holds the **instructions and data of
  the running program** for the processor to fetch. Answer in context.

### Q08.4–Q08.5 (1+2) · 4.7.1.1 buses
- Data bus width: **more bits moved at once**. To double addressable
  memory, widen the **address bus** by one line. Many didn't attempt —
  naming a bus was a free guess.

### Q09.2 (4) · 4.7.3.5 a short assembly program
- Few full marks: the result was not **stored back** to memory.
  Traps: memory addresses in CMP instead of registers; a branch with no
  label.

### Q10.1 (2) · 4.9.1.2 start/stop bits
- Same as A-level 2022: start bit **synchronises the receiver's clock
  with the transmitter's**; stop bit lets the next start bit be seen.

### Q10.4 (2) · 4.9.2.1 star behaving as a bus
- Three quarters scored nothing. A switch can create a temporary path
  between two nodes using a bus protocol, so the physical star behaves
  logically as a bus.

### Q11 (12) · 4.8.1 + 4.5.6.9 smart speakers and lossy compression
- Strong on ethics; better answers considered accents, languages and
  cultures.
- Misconceptions: lossy compression anonymises the voice, or strips
  background noise and silence. It removes what the ear **can't
  perceive**, so the difference is hard to hear.

## June 2023

### Q01.3 / Q01.5 · 4.5.1.1 number sets
- The real numbers are the rationals and irrationals together (a third
  missed it). Ordinal: a number giving an object's **position in an
  ordered sequence**, not just "position".

### Q03.2 (1) · 4.5.4.1 binary addition
- Fill in the **carry row** — the question asked for it, and the right
  sum without it lost the mark.

### Q03.3 (2) · 4.5.4.3 subtraction by two's complement
- Negate the number being **subtracted** (36 → −36) and add it to 27.
  Traps: negating 27, or negating both.

### Q03.4 (1) · 4.5.4.3 8-bit two's complement range
- −128 to 127. Trap: −256 to 255.

### Q03.5 (2) · 4.5.4.4 fixed point
- Traps: ignoring the point (221), or putting two bits after it instead
  of before (55.25). Read where the point sits.

### Q04.1–Q04.2 (1+2) · 4.5.5.3 majority voting vs parity
- "More bits, more accurate" scored nothing: each bit is sent three times
  and the receiver takes the majority, so a single flipped copy is
  corrected. Parity: faster, as fewer bits are sent.

### Q05.1 (1) · 4.5.6.4 bitmap size
- Trap: multiplying by the number of colours instead of the **colour
  depth** in bits.

### Q05.3 (1) · 4.5.6.7 sampling resolution
- Half failed: it is the **number of bits per sample**, not "quality".

### Q05.5 (2) · 4.5.6.8 MIDI
- A third full marks; "better quality" scored nothing. Smaller files;
  easy to change notes or instruments.

### Q06.1 (2) · 4.6.1.2 libraries
- Not "storing data": prewritten, tested routines you can call — saves
  time, fewer errors.

### Q06.2 (6) · 4.6.2.1 high- vs low-level
- "User-friendly" and "close to the hardware" were Level 1. Name the
  features: selection and iteration structures, data structures,
  procedures, portability vs direct register/memory control.

### Q07.2 (2) · 4.6.4.1 write the Boolean expression
- Use AQA's notation (· + ⊕ and overbar); words were accepted this year
  only.

### Q07.3 (4) · 4.6.5.1 simplification
- The precedence trap again: in A·B + B·Ā, B + B is not the next step.

### Q08.1 (2) · 4.7.3.1 the status register
- Over half scored nothing. It holds flags (carry, zero, negative,
  overflow) set by the last operation and read by conditional branches.

### Q09 (4) · 4.7.3.5 assembly loop
- Capped at 3 when it didn't work every time: the loop label must sit
  **before the CMP** (the WHILE test), not before the body's ADD.

### Q10 (2) · 4.7.3.7 performance, in context
- Two thirds scored nothing with generic factors; tie the factor to the
  device in the question.

### Q11 (9) · 4.8.1 + 4.5.6.4 an AI photo app
- Strong on ethics (bias, cultural assumptions); weaker on the camera,
  which capped answers at Level 2. Each sensor gives an electrical
  signal that is converted to binary.

### Q12.1–Q12.3 (2+2+2) · 4.9.2.3 + 4.9.3.2 wireless
- SSID names the **network**, not the access point.
- WPA2 **encrypts the data** — not just "a password to join".
- MAC filtering in a coffee shop: impractical, staff must add every
  customer's device, and MACs can be spoofed — apply it to the scene.

### Q13.1–Q13.2 (2+2) · 4.9.2.1–2 star topology and client-server
- The centre of a star is a **switch**, not a server.
- Client-server: the client **requests**, the server **responds**.

### Q14 (3) · 4.7.4.1 RFID in context
- Generic points ("portable") lacked depth; relate each feature to the
  scenario.
